# Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

# Планировщик задач на Go

Веб-приложение TODO-лист с поддержкой повторяющихся задач, реализованное на языке Go.  
Позволяет добавлять, редактировать, удалять задачи, выполнять их, а также задавать правила повторения: ежедневно, ежегодно, по дням недели и месяца.

---

## Реализованные функции

- [x] Простая база данных SQLite (`scheduler.db`)
- [x] REST API: `/api/task`, `/api/tasks`, `/api/task/done`, `/api/nextdate`, `/api/signin`
- [x] Повторы задач:
  - `d N` — через N дней
  - `y` — ежегодно
  - `w 1,3,5` — по дням недели (1 — понедельник)
  - `m 1,-1 1,2` — по дням месяца и месяцам
- [x] Поиск задач по дате и тексту
- [x] Аутентификация через JWT (по паролю из переменной окружения `TODO_PASSWORD`)
- [x] Поддержка Docker

---

## Запуск локально

1. Склонируйте репозиторий и перейдите в каталог проекта.
2. Установите переменные окружения:

```bash
export TODO_PORT=7540
export TODO_DBFILE=./scheduler.db
export TODO_PASSWORD=12345
```

3. Установите зависимости:

```bash
go mod tidy
```

4. Запустите сервер:

```bash
go run main.go
```

5. Откройте в браузере: http://localhost:7540

---

## Запуск тестов

Убедитесь, что сервер запущен на фоне (порт 7540), затем:

```bash
go test ./tests
```

### Дополнительные параметры в `tests/settings.go`:

```go
var Port = "7540"
var DBFile = "../scheduler.db"
var Token = "" // Если включена авторизация — вставьте JWT токен
var Search = true
var FullNextDate = true
```
---

## Сборка и запуск через Docker

1. Соберите образ:

```bash
docker build -t todo-scheduler .
```

2. Запустите контейнер:

```bash
docker run -it --rm -p 7540:7540 -v $(pwd)/scheduler.db:/root/scheduler.db todo-scheduler
```

(На Windows замените `$(pwd)` на абсолютный путь)

## Аутентификация

Если переменная `TODO_PASSWORD` задана, пользователь сначала увидит форму входа (`/login.html`).

Для получения токена:

```bash
curl -X POST http://localhost:7540/api/signin   -H "Content-Type: application/json"   -d '{"password": "12345"}'
```
